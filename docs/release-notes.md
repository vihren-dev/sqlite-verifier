Installable engineering preview for SQLite 3.51.0 schema-extension verification.

Each platform archive includes a pinned Lean runtime and an offline Nix cache;
Nix is an installation prerequisite. See the README inside the archive.
Only the documented ordinary nullable CREATE TABLE and ADD COLUMN subset is
supported. Synthetic examples exercise reusable requirements, checked negative
arguments, and explicit safe failure. These are engineering results, not a claim
that real-pilot acceptance or roadmap Step 1 product approval is complete.
