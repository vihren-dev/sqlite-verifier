## Current state

C6 is complete at `3ce0820b`: v4 contains 1,264 generic cases with full native
replay, bound source/triage evidence and a retained baseline over all 3,500
requirement rows. The synthetic corpus contains two recorded cases. C7 has no
replay-tier implementation, measured sample or final baseline views yet.

The existing full model target passed 239 tests in 220.79 seconds. It remains
the full correctness check. `just test` currently builds all Nix test targets,
then runs host pytest with a partial list of exclusions. CI's test scope calls
that same recipe. A fast local tier needs distinct target selection while CI
and package checks retain the full target.

`progress.py` already retains all 3,500 requirement rows and per-case alias
deduplication, but defaults to v3 and has no part/feature/shard counters. The v4
loader already validates ordered shard counts, profiles, payload digests and
optional retained extraction/fidelity evidence.
