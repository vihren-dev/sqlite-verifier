The planning commit is `bff34cc7`. The working change upgrades Lean to
4.34.1, adapts the existing patch to lean4export v4.34.0, updates both gates
to the kernel replay API and changes the runtime's version guard. Current
runtime documentation is updated; historical ADRs remain unchanged.

Both native runtime builds pass. macOS `just test-full` completed with exit
zero. Its source checks pass (321 tests and 28 subtests), model checks pass
(322 tests with one expected Tcl skip), and every other full Nix target
passes. The retained log is `build/lean-4341-macos-full.log`.

macOS Nix infrastructure checks pass (68 tests), and the extracted archive
passes all 21 installed-runtime checks. The three patched-exporter
baselines return VERIFIED, VIOLATED and VERIFIED as expected. The
[Darwin evidence report](../reports/20261006-lean-4341-upgrade-darwin.json)
binds the JUnit results, runtime, archive and baseline hashes.

The first Linux validation stopped at an existing test environment assumption:
`tests/test_pytest_harness.py:140` invokes `/bin/ps`, absent on the NixOS
host even though `ps` is available on PATH. Its source suite reports
318 passed, two expected CLI skips and one failure. Linux Nix and
installed-package checks did not start in that attempt. The owner then
authorized locating `ps` on PATH. The one-line portability fix passes the
actual process-group timeout test on macOS (one test, 1.54 seconds).
Linux validation has resumed in the same source directory, with the
corrected test and unchanged compiled runtime; remote PID 184656 owns
that run. No release or completed upgrade is claimed.
