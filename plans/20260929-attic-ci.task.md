# Attic-backed CI

Created 2026-09-29. Status: DONE (implementation and local/live validation).

Linux and macOS CI use the private cache at cache.vihren.dev/sqlite-verifier
instead of restoring/saving whole GitHub Nix-store archives. Nix retains control
of build and test reuse. Jobs without read credentials (including fork PRs)
build normally using public upstream dependencies. Successful main jobs upload
the runtime, four test outputs, and custom SQLite dependencies. Other refs never
receive the upload token. Existing tests and fresh installed acceptance remain.

Credentials must not enter repository files, artifacts or logs. The upload token
belongs to a GitHub environment restricted to the main branch. Read credentials
are repository secrets. Native daemon configuration must work with the existing
untrusted runner account. Clients use the pinned nixpkgs Attic package.

Validate workflow syntax, existing CI routing/orchestration tests, a real signed
cache download with the runner's netrc format, and the pinned client's authenticated
upload. Confirm environment restrictions and secret names through GitHub. A hosted
two-platform run follows publication; do not move main or silently claim a local
test validates hosted Actions. Commands have explicit timeouts.

Relevant sources: .github/workflows/ci.yml, build-support/default.nix,
build-support/tests.nix, tools/ci_checks.py, justfile, docs/ci.md.
