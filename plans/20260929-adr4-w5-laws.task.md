# General laws

Created 2026-09-29. Status: DONE.
Spec: [ADR 0004](../docs/adr-0004-model-conformance-validation.md).

## Required outcomes

Rollback after a successful transaction-free body restores the initial database; every modeled statement failure preserves visible and committed state; successful ADD COLUMN preserves row count, rowids and existing cells and appends NULL. These are universal Lean theorems over production advance/runSql, with the ADR preconditions, and native property checks accompany them.

## Observable validation

Kernel compilation and axiom audits reject sorryAx, ofReduceBool and _native. Native transaction, failing-write and populated ADD cases exercise the same preconditions.
